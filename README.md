## 📱 About the Project

SmartSpend is a personal finance application built to make everyday expense tracking easier. This project represents my journey of turning an idea into a working Android application using an AI-assisted app-building approach.

## ✨ Features

- Record and manage income and expenses.
- View financial summaries on the dashboard.
- Organize personal financial records.
- Use a simple and accessible interface.
